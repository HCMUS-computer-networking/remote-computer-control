# TÀI LIỆU KỸ THUẬT: HỆ THỐNG AGENT (PROJECT SPECIFICATIONS)

## 1. TỔNG QUAN HỆ THỐNG

Dự án là công cụ thực hành mô phỏng quản trị và giám sát máy tính (Agent) từ xa, phục vụ môn Mạng máy tính. Hệ thống tuân thủ kiến trúc **3-Tier Decoupled Architecture** bao gồm:

* **Controller (Web Application):** Trạm điều khiển trung tâm chạy trên trình duyệt, thực hiện gửi lệnh (đơn lẻ hoặc Broadcast nhóm), quản lý trạng thái, hiển thị kết nối và giao diện giám sát thời gian thực.
* **Gateway (Relay Proxy Server):** Node định tuyến mạng chạy WebSockets. Hoạt động song công (Full-Duplex), nhận lệnh JSON từ Controller, biên dịch và đẩy xuống đúng AgentId. Đồng thời, tiếp nhận dữ liệu (Text/Binary) từ Agent và phản hồi ngược lên. Tích hợp tính năng UDP Broadcast để Auto-Discovery mạng LAN.
* **Agent (Windows Application):** Phần mềm Client độc lập viết bằng C# .NET 8.0. Đây là lớp thực thi mệnh lệnh cuối cùng (Command Execution Layer), thiết kế hướng module linh hoạt (DI) kết hợp với các rào cản bảo mật nghiêm ngặt (Privacy-first) để bảo vệ quyền lợi người dùng.

## 2. ĐẶC TẢ CHỨC NĂNG (FUNCTIONAL SPECS)

Agent bao gồm 7 phân hệ chính, được thiết kế để chạy đa luồng và đồng bộ:

### 2.1. Phân hệ Quản lý Ứng dụng (Application Module)

* Truy xuất thời gian thực danh sách ứng dụng có giao diện đang chạy.
* Đo lường CPU % qua Performance Counter (với 50ms delay) và RAM WorkingSet.
* Hỗ trợ lệnh Start/Stop (theo PID và ProcessName), được kiểm duyệt tuyệt đối bởi danh sách an toàn Whitelist.

### 2.2. Phân hệ Quản lý Tiến trình (Process Module)

* Giám sát hệ thống tầng thấp.
* Thu thập luồng song song (`Parallel.ForEach`) toàn bộ tiến trình để tính toán Delta CPU Time.
* Hỗ trợ Force Kill tiến trình qua PID với cơ chế chạy bất đồng bộ và Timeout 2 giây để chống treo Agent.

### 2.3. Phân hệ Giám sát Màn hình (Stream Module)

* Khai thác đồ họa GDI+ để stream hình ảnh liên tục định dạng JPEG.
* Ép kích thước nội suy chuẩn 1280x720 để tối ưu băng thông.
* Duy trì luồng truyền đa phương tiện 2-Phases (Metadata + Binary Bytes) thông qua bộ đếm `PeriodicTimer` (mặc định 24 FPS) và được bảo vệ bởi Semaphore chống sụp đổ luồng.

### 2.4. Phân hệ Ghi nhận Thao tác (Keylogger Module)

* Giám sát toàn bộ văn bản nhập từ thiết bị.
* Móc trực tiếp vào API Hệ điều hành (`WH_KEYBOARD_LL`) và phân tách trạng thái phím bổ trợ (Shift, Ctrl, Alt).
* Chống spam băng thông bằng cách nhốt log vào Buffer và xả hàng loạt về Server mỗi 3 giây; tự động dọn dẹp Message Loop khi dừng.

### 2.5. Phân hệ Quản trị Tệp tin (File Sandbox Module)

* Truyền nhận file lớn hai chiều mà không bị ngắt bộ nhớ.
* Ép luồng đọc/ghi vào Sandbox (`C:\AgentSandbox\`) để chặn Path Traversal.
* Tự động băm (Hash) nội dung tệp bằng SHA-256; upload xử lý theo phân mảnh (Chunking) có bộ khóa (`_chunkLock`) thứ tự.

### 2.6. Phân hệ Quan sát Camera (Webcam Module)

* Giám sát thị giác từ xa thông qua OpenCV.
* Cưỡng chế phân giải 720p.
* Stream liên tục khung hình (Mat -> Bitmap -> JPEG); tự động dọn dẹp tài nguyên phần cứng nếu luồng socket rớt mạng.

### 2.7. Phân hệ Điều khiển Nguồn (Power Module)

* Cấp quyền can thiệp cấp thấp cho Admin: Lệnh Sleep, Restart, Shutdown, Lock screen thông qua tập lệnh CLI của Windows.

## 3. TIÊU CHUẨN BẢO MẬT & QUYỀN RIÊNG TƯ

Triết lý thiết kế hướng tới việc bảo vệ sinh viên và ngăn chặn lạm dụng quyền với các nguyên tắc bắt buộc:

* **Minh bạch Thực thi (User Consent):** Mọi can thiệp sâu (Quay màn hình, Webcam, Keylogger, Sleep, Restart, Shutdown) phải kích hoạt Hộp thoại (Consent Popup). Người dùng có 30 giây để xác nhận Đồng Ý. Nếu bỏ qua hoặc Từ Chối, lệnh sẽ bị hủy.
* **Chống Tấn Công Spam (Anti-DoS UI):** Nếu Controller spam lệnh bật pop-up, Agent sẽ thả rớt (reject) mọi lệnh phía sau thông qua HashSet cho tới khi pop-up đầu tiên được xử lý.
* **Sự Thấu Hiểu Thị Giác (Webcam Transparency):** Cưỡng chế Delay 10s kết hợp giao diện đếm ngược màu đỏ trước khi Camera bật. Khi quay, điểm ảnh đỏ (Red Dot) Overlay sẽ nhấp nháy trên màn hình để báo hiệu người dùng.
* **Phân Vùng Cách Ly (Sandbox & Whitelist):** Agent chỉ khởi chạy phần mềm trong Whitelist (đồng bộ từ RAM/JSON) và giới hạn thao tác tệp tin trong phân vùng gốc, khóa cứng Path Traversal.
