# Agent System - Protocol Specification

This document defines the communication protocol between the Agent, Gateway, and Controller in the Agent System.

## 1. Transport Layer
* **Protocol**: WebSockets (WS / WSS) for full-duplex communication.
* **Endpoint**: `<gateway_url>/agent?key=<auth_key>`
* **Auto-Discovery**: UDP Broadcast on Port `8888`. Gateway broadcasts `GATEWAY_ANNOUNCE|wss://<ip>:<port>`.

## 2. Standard Message Format
All textual communication uses JSON. The standard command packet structure from the Gateway to the Agent is:

```json
{
  "type": "string",          // Message type (e.g., permission_request, policy_update)
  "command_id": "string",    // Unique identifier for the command
  "module": "string",        // Target module (e.g., app_start, proc_kill, etc. or module routing key)
  "action": "string",        // Specific action to perform
  "params": { },             // Dynamic JSON object containing parameters
  "target_agents": [ ],      // Array of Agent IDs (or ["all"] for broadcast)
  "feature": "string"        // Requested feature for permissions (e.g., screen, webcam, file)
}
```

## 3. Connection Lifecycle

### 3.1 Registration
Upon establishing the WebSocket connection, the Agent sends a `REGISTER` packet:
```json
{
  "type": "REGISTER",
  "agent_id": "string",
  "hostname": "string",
  "ip": "string",
  "os": "string"
}
```

### 3.2 Heartbeat
To keep the connection alive, the Agent sends a PING every 15 seconds.
* **Agent -> Gateway**: `{"type":"PING"}`
* **Gateway -> Agent**: `{"type":"PONG"}` (Implied, ignored by Agent's dispatcher)

### 3.3 Reconnection
If the Agent disconnects and successfully reconnects, it sends `REGISTER` followed by:
```json
{
  "type": "permissions_reset",
  "agent_id": "string",
  "message": "Agent reconnected. Please re-grant permissions."
}
```

## 4. Security & Permissions Policies

### 4.1 Permission Request
Before accessing sensitive features, the Controller requests permission:
* **Gateway -> Agent**: `{"type": "permission_request", "command_id": "...", "feature": "screen"}`
* **Agent -> Gateway**: `{"type": "permission_result", "agent_id": "...", "feature": "screen", "granted": true/false}`

### 4.2 Permission Revoke & Module Stopping
* **Revoke**: `{"type": "permission_revoke", "feature": "..."}`
* **Stop Module**: `{"type": "stop_module", "feature": "screen", "params": {}, "command_id": "..."}`

### 4.3 Policy Update (Whitelist & Sandbox)
* **Gateway -> Agent**: 
  ```json
  {
    "type": "policy_update",
    "command_id": "...",
    "params": {
      "app_whitelist": ["notepad", "calc"],
      "sandbox_path": "C:\NewSandbox\"
    }
  }
  ```
* **Agent -> Gateway**: `{"type": "policy_update_result", "success": true, "message": "..."}`

## 5. Module Commands

### 5.1 Application Module (AppModule)
* **List Apps**:
  * Action: `app_list`
  * Response: `{"type": "app_list_result", "apps": [{"name": "...", "display_name": "...", "status": "...", "cpu_percent": 0.0, "ram_mb": 0.0, "in_whitelist": true}]}`
* **Start App**:
  * Action: `app_start`, Params: `{"name": "notepad"}`
  * Response: `{"type": "app_action_result", "success": true/false, "message": "..."}`
* **Stop App**:
  * Action: `app_stop`, Params: `{"name": "notepad"}`

### 5.2 Process Module (ProcessModule)
* **List Processes**:
  * Action: `proc_list`
  * Response: `{"type": "proc_list_result", "processes": [{"pid": 1234, "name": "...", "username": "...", "cpu_percent": 0.0, "ram_mb": 0.0}]}`
* **Kill Process**:
  * Action: `proc_kill`, Params: `{"pid": 1234}`
  * Response: `{"type": "proc_kill_result", "pid": 1234, "success": true/false}`

### 5.3 System Info Module (SysInfoModule)
* **Get SysInfo**:
  * Action: `sysinfo`
  * Response: `{"type": "sysinfo_result", "cpu_percent": 0.0, "ram_used_mb": 0.0, "ram_total_mb": 0.0, "disk_used_gb": 0.0, "disk_total_gb": 0.0, "uptime_seconds": 0, "hostname": "...", "ip": "...", "os": "..."}`

### 5.4 Power Module (PowerModule)
* **Actions**: `shutdown`, `restart`, `sleep`, `lock` (passed as `action` parameter).
* Response: `{"type": "power_result", "action": "...", "confirmed": true/false}`

### 5.5 Input Module (InputModule)
* **Mouse Move**: `input_mouse_move`, Params: `{"x": 100, "y": 100}`
* **Mouse Click**: `input_mouse_click`, Params: `{"button": "left|right|middle", "action": "click|down|up"}`
* **Key Input**: `input_key`, Params: `{"vk": 13, "action": "press|down|up"}`
* **Type Text**: `input_type`, Params: `{"text": "hello"}`
* Response: `{"type": "input_result", "success": true}`

### 5.6 Keylogger Module (KeyloggerModule)
* **Start**: `keylog_start`
* **Stop**: `keylog_stop`
* **Log Stream (Periodic)**: `{"type": "keylog", "events": [{"key": "A", "ctrl": false, "alt": false, "shift": true, "timestamp_ms": 123456789}]}`

## 6. Binary Transmission (Streaming & Files)

### 6.1 Screen Streaming (StreamModule)
Streams consist of a JSON metadata frame followed by a Raw Binary frame.
* **Start Stream**: Action: `screen_stream`, Params: `{"fps": 24, "quality": 70}`
* **Stop Stream**: Action: `screen_stream_stop`
* **Screenshot**: Action: `screenshot`, Params: `{"quality": 90}`
* **Frame Metadata (JSON)**: `{"type": "frame_meta", "module": "screen", "agent_id": "...", "command_id": "...", "x": 0, "y": 0, "w": 1280, "h": 720, "is_keyframe": true, "len": 12345, "seq": 1, "timestamp_ms": 123456789}`
  * Note: `x, y, w, h` define the Bounding Box rectangle of the changed screen area (Software Delta Encoding). `is_keyframe` is `true` for full frame updates (sent every 30 frames or initial frame).
* **Followed immediately by**: `[BINARY BYTES (JPEG of the Bounding Box cropped area)]`

### 6.2 Webcam Streaming (WebcamModule)
Similar to Screen Streaming.
* **Start Webcam**: Action: `webcam_start`, Params: `{"fps": 15, "quality": 60}`
* **Stop Webcam**: Action: `webcam_stop`
* **Frame Metadata (JSON)**: `{"type": "frame_meta", "module": "webcam", "w": 1280, "h": 720, "len": 12345, "seq": 1, "timestamp_ms": 123456789}`
* **Followed immediately by**: `[BINARY BYTES (JPEG)]`

### 6.3 File System Module (FileModule)
* **List Directory**: 
  * Action: `fs_list`, Params: `{"path": "/"}`
  * Response: `{"type": "fs_list_result", "path": "/", "entries": [{"name": "...", "type": "file|directory", "size": 1024, "modified_ms": 123456789}]}`
* **Download File (Gateway <- Agent)**:
  * Action: `fs_get`, Params: `{"path": "/file.txt", "transfer_id": "tx123"}`
  * Response (Per Chunk): `{"type": "fs_get_result", "transfer_id": "tx123", "success": true, "chunk_index": 0, "total_chunks": 5, "sha256": "..."}`
  * **Followed immediately by**: `[BINARY BYTES (File Chunk)]`
* **Upload File (Gateway -> Agent)**:
  * Action: `fs_put`, Params: `{"path": "/file.txt", "chunk_index": 0, "total_chunks": 5, "transfer_id": "tx123"}`
  * **Gateway sends Binary Frame**: `[TransferID Length (1 byte)] + [TransferID (UTF-8 bytes)] + [Chunk Data]`
  * Agent Response (Chunk Ack): `{"type": "fs_put_result", "transfer_id": "tx123", "chunk_index": 0, "success": true}`
  * Agent Response (Complete): `{"type": "fs_put_complete", "transfer_id": "tx123", "success": true, "sha256": "..."}`
