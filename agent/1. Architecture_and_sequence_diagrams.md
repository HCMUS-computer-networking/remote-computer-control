# Architecture & Sequence Diagrams

## 1. System Architecture

```mermaid
graph TD
    subgraph Controller [Controller Tier (Web App)]
        UI[Web Dashboard]
    end

    subgraph Gateway [Gateway Tier (Relay Proxy)]
        WS_Server[WebSocket Server]
        UDP_Bcast[UDP Broadcast Port 8888]
    end

    subgraph Agent [Agent Tier (Windows Client)]
        UI_Manager[UI Manager / Consent Form]
        Sec_Manager[Security Manager / Whitelist & Sandbox]
        WS_Client[WebSocket Client]
        Dispatcher[Message Dispatcher]
        
        subgraph Modules
            AppM[App Module]
            ProcM[Process Module]
            ScreenM[Stream Module]
            WebcamM[Webcam Module]
            FileM[File Module]
            KeyM[Keylogger Module]
            PowerM[Power Module]
        end
    end

    UI <-->|WSS / API| WS_Server
    WS_Server <-->|Full-Duplex WSS| WS_Client
    UDP_Bcast -.->|Auto Discovery| WS_Client
    
    WS_Client --> Dispatcher
    Dispatcher --> Sec_Manager
    Dispatcher --> UI_Manager
    Dispatcher --> Modules
    Modules --> WS_Client
```

## 3. Sequence Diagrams

### 3.1 Connection & Auto-Discovery

```mermaid
sequenceDiagram
    participant Agent as Agent Client
    participant UDP as Network LAN
    participant Gateway as Gateway Server

    Agent->>UDP: Listen on UDP 8888 (5s timeout)
    Gateway-->>UDP: GATEWAY_ANNOUNCE|wss://ip:port
    UDP-->>Agent: Discovered Gateway URL
    Agent->>Gateway: Connect WebSocket (wss://ip:port/agent?key=...)
    Gateway-->>Agent: Connection Established
    Agent->>Gateway: {"type": "REGISTER", "agent_id": "...", ...}
    
    loop Every 15 seconds
        Agent->>Gateway: {"type": "PING"}
        Gateway-->>Agent: {"type": "PONG"}
    end
```

### 3.2 Permission Request Flow (User Consent)

```mermaid
sequenceDiagram
    participant Controller
    participant Gateway
    participant Agent as Agent Dispatcher
    participant UI as UIManager (Consent)
    participant Module as Target Module

    Controller->>Gateway: Request Feature Access (e.g., webcam)
    Gateway->>Agent: {"type": "permission_request", "feature": "webcam"}
    Agent->>UI: ShowConsentPopupAsync("webcam", 30000ms)
    
    alt User Approves
        UI-->>Agent: true
        Agent->>Agent: Add "webcam" to _grantedFeatures
        Agent->>Gateway: {"type": "permission_result", "granted": true}
        Controller->>Gateway: Execute command (e.g., webcam_start)
        Gateway->>Agent: {"type": "webcam_start", ...}
        Agent->>Module: ExecuteAsync()
    else User Rejects / Timeout
        UI-->>Agent: false
        Agent->>Gateway: {"type": "permission_result", "granted": false}
    end
```

### 3.3 Screen Streaming (Metadata + Binary Transmission)

```mermaid
sequenceDiagram
    participant Module as StreamModule
    participant Agent as AgentContext
    participant Gateway
    participant Controller

    Gateway->>Module: ExecuteAsync("screen_stream", fps=24, quality=70)
    Module->>Agent: {"type": "stream_started"}
    Agent->>Gateway: JSON Response
    
    loop Every Frame (e.g., 24 FPS)
        Module->>Module: Capture Screen & Compress JPEG
        Module->>Agent: SendResponse({"type": "frame_meta", "len": 12345, ...})
        Agent->>Gateway: JSON Metadata
        Gateway->>Controller: JSON Metadata
        
        Module->>Agent: SendBinaryFrame(byte[])
        Agent->>Gateway: Raw Binary Frame (12345 bytes)
        Gateway->>Controller: Raw Binary Frame
    end
    
    Gateway->>Module: ExecuteAsync("screen_stream_stop")
    Module->>Module: Stop Capture Loop
```

### 3.4 File Upload to Agent (Chunking)

```mermaid
sequenceDiagram
    participant Gateway
    participant AgentContext as Agent Context
    participant FileModule
    participant Disk as Sandbox Disk

    Gateway->>AgentContext: {"action": "fs_put", "chunk_index": 0, "transfer_id": "tx1"}
    AgentContext->>FileModule: ExecuteAsync()
    FileModule->>FileModule: Register transfer_id waiter
    
    Gateway->>AgentContext: Binary Frame [1 byte len][tx1][Binary Data]
    AgentContext->>FileModule: HandleBinaryFrame()
    FileModule->>Disk: Write Chunk 0 to file
    FileModule->>Gateway: {"type": "fs_put_result", "chunk_index": 0, "success": true}
    
    Note over Gateway, Disk: ... Repeat for subsequent chunks ...
    
    Gateway->>AgentContext: {"action": "fs_put", "chunk_index": N-1, "total_chunks": N}
    FileModule->>Disk: Write Last Chunk
    FileModule->>FileModule: Compute SHA-256
    FileModule->>Gateway: {"type": "fs_put_complete", "sha256": "..."}
```
